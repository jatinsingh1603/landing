## The Problem

> **₹17–18 Crore** — the average cost of a data breach in India. In most cases, the attacker didn't break in through the front door. **They walked in through a vendor.**

India saw **15 lakh+ cyber incidents** reported to CERT-In in a single year. Over **50% of enterprise breaches globally** trace back to a third-party vendor — a supplier, a SaaS tool, an API integration, a payment processor. The threat isn't just external. **It lives inside your supply chain.**

### Real Incidents. Same Root Cause.

| Year | Company | Records Exposed | Entry Point |
|------|---------|----------------|-------------|
| 2017 | Reliance Jio | 120 Million | Unvetted third-party partner with database access |
| 2019 | Airtel | 325 Million+ | Unauthenticated third-party API endpoint |
| 2024 | Star Health Insurance | 31 Million | Uncontrolled internal & partner access channels |
| 2024 | Indian Fintech Ecosystem | Crores | Unvetted third-party vendor integrations |

Every breach. Same pattern: a trusted vendor, no formal assessment, access that should never have been granted.

## What is SwiftSane?

SwiftSane is a **vendor security lifecycle platform** built specifically for Indian tech companies. It gives security and compliance teams a complete, structured system to onboard, assess, test, and continuously monitor every vendor in their ecosystem — **before they become a liability.**

```
  VENDOR APPEARS       →    DUE DILIGENCE    →    ONBOARDING
        ↓                                              ↓
  VAPT EXECUTION       ←   VENDOR ASSESSMENT  ←  CRITICALITY SCORING
        ↓
  AUDIT-READY REPORT
```

## Core Features

### `01` — Vendor Due Diligence
Before any vendor conversation advances, SwiftSane runs a comprehensive check — security questionnaires, compliance certifications, infrastructure documentation, and digital footprint analysis.

- Automated security questionnaire distribution
- Certification & documentation verification  
- Digital footprint & reputation scanning
- Initial red flag detection

### `02` — Vendor Onboarding
Structured, approval-gated onboarding workflow that replaces scattered email chains. Every vendor goes through a standardized security intake process before system access is granted.

- Multi-stakeholder approval gates
- Centralized vendor profile repository
- Access control documentation
- Compliance checklist automation

### `03` — Criticality Assessment
Not every vendor carries the same risk. SwiftSane scores each vendor based on data access levels, system integration depth, regulatory exposure, and business dependency.

```
CRITICAL  ██████████  Core banking API, KYC providers, payment processors
HIGH      ████████    Analytics platforms, auth integrations
MEDIUM    ██████      SaaS tools with limited data access
LOW       ████        Marketing & communication tools
```

### `04` — Continuous Vendor Assessment
Ongoing compliance monitoring and security posture tracking. SwiftSane flags compliance drift and generates reports aligned to RBI, SEBI, and DPDP Act requirements.

- Security posture change tracking
- Regulatory alignment monitoring
- Audit-ready assessment reports

### `05` — VAPT
Penetration testing specifically for your vendor ecosystem — testing whether vendor APIs, integrations, and exposed infrastructure can be exploited to access your environment.

- Vendor-specific attack surface scanning
- API & integration penetration testing
- Vulnerability findings mapped to vendor relationships
- Remediation roadmap per vendor
